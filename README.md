# UPI Fraud Detection System

## Project Overview
A Machine Learning-based UPI Fraud Detection System designed to identify potentially fraudulent transactions using transaction-related data.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- SHAP
- Streamlit
- Docker

## Project Structure

- `app/` – Streamlit application
- `ml/notebooks/` – Machine learning experiments
- `ml/src/` – Machine learning source code
- `ml/artifacts/` – Trained model artifacts
- `data/` – Dataset storage
- `reports/` – Analysis and evaluation reports
- `tests/` – Testing
- `deployment/` – Deployment configuration
